# Моя Сказка — лендинг Telegram-бота

Одностраничный сайт для Telegram-бота, который придумывает персональные детские сказки с иллюстрациями.
Сам сайт ничего не генерирует — его задача заинтересовать и увести в бота.

- Стек: Astro 7, чистый HTML/CSS, один инлайновый скрипт (~15 строк) для появления блоков при скролле.
- Без фреймворков, без бандлера JS, без внешних CDN: шрифты и иллюстрации лежат локально.
- CSS инлайнится в HTML при сборке (`build.inlineStylesheets: "always"`), поэтому первый экран рисуется сразу.

---

## Быстрый старт

```bash
npm install
npm run dev       # http://localhost:4321
```

Сборка и локальный просмотр продакшн-версии:

```bash
npm run build     # результат в dist/
npm run preview   # http://localhost:4321
```

Требуется Node.js 22.23.4 или новее (ограничение Astro 7).

## Где менять ссылку на бота

**`src/data/site.ts` → `TELEGRAM_URL`**

```ts
export const TELEGRAM_URL = "https://t.me/moya_skazka_bot"; // ⚠️ ЗАМЕНИТЕ
```

Обе CTA-кнопки (первый экран и финальный блок) берут адрес только отсюда — менять в одном месте.
Больше ссылок в разметке нет.

В этом же файле:

- `SITE_URL` — домен сайта (нужен для canonical и Open Graph);
- `SEO` — `<title>` и описание;
- `ILLUSTRATIONS` — точки подмены иллюстраций на растровые файлы (см. ниже).

Домен также дублируется в `astro.config.mjs` (`site`), если понадобится карта сайта или абсолютные ссылки.

## Иллюстрации

Все три сцены нарисованы как инлайн-SVG в единой акварельной палитре — это даёт нулевые сетевые запросы,
идеальную резкость на ретине и одинаковый стиль:

| Файл | Где используется |
| --- | --- |
| `src/components/art/ForestScene.astro` | первый экран: мама с мальчиком в волшебном лесу |
| `src/components/art/FoxScene.astro` | пример сказки «Миша и лесной друг» |
| `src/components/art/CastleScene.astro` | фон финального блока: замок, луна, звёзды |

Если появятся нарисованные иллюстрации (WebP/AVIF), положите их в `public/images/` и укажите пути в
`src/data/site.ts`:

```ts
export const ILLUSTRATIONS = {
  hero: "/images/hero.webp",       // 720×820 (или кратное)
  example: "/images/example.webp", // 560×560
  finale: "/images/finale.webp",   // 1440×500
};
```

Компонент `Illustration.astro` сам переключится с SVG на `<img>`: у главного экрана `loading="eager"` и
`fetchpriority="high"`, у остальных — `loading="lazy"` и `decoding="async"`. Ничего больше править не нужно.

## Структура

```
src/
  components/
    Header.astro        логотип + название (не ссылка — чтобы не было третьей кнопки)
    Hero.astro          первый экран: заголовок, подзаголовок, CTA, иллюстрация
    HowItWorks.astro    «Как рождается сказка?»: три шага + пример-разворот книги
    Finale.astro        финальный призыв: заголовок, описание, CTA, сцена с замком
    Footer.astro        минималистичный футер
    Illustration.astro  SVG или <img> — одна точка на все иллюстрации
    Icon.astro          три инлайновые иконки (книга, перо, звёздочки)
    art/                три SVG-сцены
  data/site.ts          ссылка на бота, SEO, пути иллюстраций
  layouts/Layout.astro  <head>: SEO, Open Graph, favicon, preload шрифтов, reveal-скрипт
  pages/index.astro     сборка страницы из секций
  styles/
    fonts.css           @font-face для локальных woff2 (генерируется)
    global.css          токены, секции, адаптив, prefers-reduced-motion
public/
  fonts/                10 файлов woff2 (Cormorant Garamond 400/600/400 italic, Nunito 400/700; latin + cyrillic)
  favicon.svg           иконка открытой книги
  og-cover.jpg          1200×630 для соцсетей
  robots.txt
scripts/fetch-fonts.mjs перекачивает шрифты с Google Fonts и пересобирает fonts.css
pics/                   рабочие скриншоты (в прод не попадают)
```

## Что учтено

**Адаптивность.** Проверено на ширинах 320, 360, 375, 414, 640, 768, 860, 899, 900, 901, 1024, 1200, 1280,
1440 и 1920 px: горизонтального скролла нет нигде. Карточки шагов перестраиваются из трёх колонок в одну
на 860 px, разворот книги — в одну колонку на 760 px, первый экран — на 900 px (текст над иллюстрацией).
Кнопки на 320 px занимают почти всю ширину и не разрывают текст на две строки.

**Производительность.** HTML одного экрана ~46 КБ со встроенным CSS; внешние запросы — только 2–9 шрифтов
(лишние подмножества не грузятся благодаря `unicode-range`) и favicon. Иллюстрации — SVG, масштабируются без
потерь и не требуют отдельных запросов.

**Доступность и анимации.** Все анимации отключаются при `prefers-reduced-motion: reduce`. У кнопок есть
`:focus-visible`. У иллюстраций — `role="img"` и `aria-label`, декоративная сцена финала — `aria-hidden`.

**SEO.** `<title>`, `description`, canonical, Open Graph (включая `og:image` 1200×630), Twitter card,
`theme-color`, favicon, `robots.txt`.

## Тексты и стиль

- Палитра: `#FAF6F0` фон, `#EDE0D1` беж, `#D8B9A7` персик, `#A8B9A3` шалфей, `#59483E` текст, `#B88C70` кнопки.
- Шрифты: Cormorant Garamond (заголовки), Nunito (текст). Оба с кириллицей, лежат локально.
- Кнопок ровно две, обе ведут в одного бота. Форм, регистрации и сбора данных нет.
- Слово «бесплатно» не используется — условия оплаты бота ещё не определены.

## Шрифты

Шрифты уже лежат в `public/fonts/`, пересборка не нужна. Если понадобится обновить или добавить начертание —
отредактируйте массив `wanted` в `scripts/fetch-fonts.mjs` и запустите:

```bash
npm run fonts
```

Скрипт скачает нужные подмножества (latin + cyrillic) с Google Fonts и перезапишет `src/styles/fonts.css`.
Если у Node нет прямого доступа к `fonts.googleapis.com`, положите ответ Google Fonts в `tmp_fonts.css`
в корне проекта — скрипт подхватит его.
